# Restaurant 

## Описание
Система управления рестораном для учета заказов, столиков и меню. Позволяет рассчитывать стоимость заказов, время ожидания и применять скидки.

## Функциональность
- Управление меню блюд
- Бронирование столиков
- Создание и обработка заказов
- Расчет стоимости и времени ожидания
- Генерация отчетов в форматах DOCX и XLSX
- Сохранение данных в SQLite базу данных

## Инструкции по запуску

### Локальный запуск
1. Установите зависимости: pip install -r requirements.txt
2. Запустите приложение: python main.py


## Использование
Выберите действие из главного меню

Для создания заказа выберите свободный столик

Добавьте блюда из меню

При необходимости примените скидку

Просмотрите итоговую информацию о заказе

## Тестирование
Для запуска тестов выполните: pytest test_restaurant.py -v
